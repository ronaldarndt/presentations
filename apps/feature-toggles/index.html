O que são feature toggles

Também conhecidas como "Feature Flags", feature toggles permitem ativar ou desativar funcionalidades sem precisar fazer deploy do sistema.

Formas de implementação

  • Configurações no banco de dados (chave especial)
  • Arquivos de configuração
  • Serviços externos (Azure AppConfig, Unleash, etc)
