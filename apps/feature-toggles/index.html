O que são feature toggles

Feature = funcionalidade

Toggle = interruptor

Ferramentas e técnicas que permitem ativar ou desativar funcionalidades sem precisar fazer deploy do sistema.

Deploy sem feature

              flowchart LR
                  A[Dev] --> B[Revisão]
                  B --> C[Teste]
                  C --> D[Merge]
                  D --> E[Deploy]
                  E -.-> F{Deu algo muito errado?}
                  F -->|Sim| G[Revert correndo]
                  G --> A
                  style E fill:#ff4081,color:#fff

Deploy com feature

              flowchart LR
                  A[Processo dev] --> E["Deploy (feature desativada)"]
                  E --> F[Ativa feature para os devs]
                  F -.-> G{Deu algo muito errado?}
                  G -->|Sim| H[Desativa feature]
                  G -->|Não| I[Ativa feature para 10% dos usuários]
                  I -.-> J{Deu algo muito errado?}
                  J -->|Sim| H
                  J -->|Não| K[Ativa feature para todo mundo]
                  K -.-> L{Deu algo muito errado?}
                  L -->|Sim| H
                  L -->|Não| N[Sucesso]
                  style F fill:#ff4081,color:#fff

Possibilidades

  • Ativar/desativar funcionalidades rapidamente
  • Testes A/B
  • Rollouts graduais
  • Selecionar quais usuários tem acesso a cada funcionalidade
  • Esconder páginas em testes

O que não são feature toggles

  • Chave especial do Secullum RH
Chaves especiais não são exatamente feature toggles, mas sim preferências de usuário. São coisas específicas para uma empresa que eles podem ativar/desativar. Feature toggles são mais voltados para toggles gerais do sistema inteiro e controlados por nós.

            async Task<IServidorCache> BuscarServidorCacheAsync() 
            {
              var usarNovoServidorCache = await contexto.FeatureToggles
                .Where(c => c.Chave == "NovoServidorCache")
                .Select(c => c.Valor)
                .FirstOrDefaultAsync();

              return usarNovoServidorCache
                ? new KeyDBCache()
                : new RedisCache();
            }

Tipos de flags

Tipo Descrição Vida
Flag de release Ativa ou desativa funcionalidades específicas Curta
Flag de experimento Ativa a funcionalidade para uma porcentagem de usuários Temporária
Flag operacional Controla aspectos operacionais do sistema Potencialmente longa
Flag de permissão Controla o acesso a funcionalidades com base em permissões Potencialmente longa

Pegadinhas

  • "Débito de flags"
  • Flags de ambiente

❌ Não é possível (de forma fácil) criar flags de ambiente, ou seja, flags que controlam a configuração do ambiente em que o sistema está rodando.

Alguns exemplos são:
  • Configurar a versão do .Net
  • Configurar a versão de uma biblioteca
  • Configurar qual migration do banco usar
