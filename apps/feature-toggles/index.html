O que são feature toggles

Feature = funcionalidade

Toggle = interruptor

Ferramentas que permitem ativar ou desativar funcionalidades sem precisar fazer deploy do sistema.

O que não são feature toggles

  • Chave especial do Secullum RH
Chaves especiais não são exatamente feature toggles, mas sim preferências de usuário. São coisas específicas para uma empresa que eles podem ativar/desativar. Feature toggles são mais voltados para toggles gerais do sistema inteiro e controlados por nós.

Formas de implementação

  • Configurações no banco de dados

            async Task<IServidorCache> BuscarServidorCacheAsync() 
            {
              var usarNovoServidorCache = await contexto.FeatureToggles
                .Where(c => c.Chave == "NovoServidorCache")
                .Select(c => c.Valor)
                .FirstOrDefaultAsync();

              return usarNovoServidorCache
                ? new KeyDBCache()
                : new RedisCache();
            }

            };
            var unleash = new DefaultUnleash(settings);
            services.AddSingleton(c => unleash);

            // ...

            var context = new UnleashContext() { UserId = m_configuracoesAmbiente.UsuarioId };

            var usarNovoServidorCache = unleash.IsEnabled("NovoServidorCache", context);
